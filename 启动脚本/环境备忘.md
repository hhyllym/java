### ⚠️ 三个必踩的坑

1. **一定要用 `mvn.cmd`，不要用 `mvn`（无后缀的 shell 脚本）。**
   在 Git Bash 里跑 `mvn` 会直接报：
   ```
   错误: 找不到或无法加载主类 org.codehaus.plexus.classworlds.launcher.Launcher
   ```
   这是 Git Bash 的路径转换把 Maven 的 classpath 弄坏了，不是 Maven 装坏了。

2. **启动后端前要清掉环境变量 `SERVER__PORT`。**
   Spring Boot 的宽松绑定会把它当成 `server.port`，于是 Tomcat 跑去监听一个随机端口，
   日志里会出现 `Tomcat initialized with port 58203` 然后 `APPLICATION FAILED TO START`。
   在自动化脚本里启动前先 `unset SERVER__PORT`。

3. **后端代码有两份，`backend-src.bak` 才是新的。**
   `D:\workSpace\springBootTest` 是 11-09 之前的旧副本，两边源码有 18 处差异
   （旧版没有 `server.address=0.0.0.0`、没有 `app.lan-ip`、旧版 Monopoly/Admin 接口也过时）。
   `启动后端.bat` 的候选列表已把 `backend-src.bak` 提到第一位。

## 3.2 手机 / 局域网访问（重点）

- 前端 dev server 已绑 `0.0.0.0:5180`，后端也绑了 `server.address=0.0.0.0`，防火墙对
  node.exe / java.exe 的 Public 入站都是允许 → **手机连同一个 WiFi 就能直接访问**。
- 访问地址 = `http://<电脑当前 WLAN IP>:5180`
- **IP 会变**（换 WiFi / 路由器就变）：`ipconfig` 看 WLAN 的 IPv4，或
  `Get-NetIPAddress -AddressFamily IPv4 | ? {$_.IPAddress -notlike '127.*'}`
- 电脑上有 VMware / WSL 的虚拟网卡（192.168.147.x、192.168.188.x、172.28.x），
  **那些 IP 手机连不上**，别用
- `app.lan-ip`（在 `application-dev.properties` 里）是「分享给同学的大富翁网址」用的，
  换网络后记得同步改
- 手机打不开的排查顺序：① IP 对不对 ② 手机和电脑同一个 WiFi 吗 ③ 8081 后端起来了吗
  （页面能开但登录报错 = 后端没起）

## 5. 接口清单（本次新增）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/home/overview` | 统计 + 分类树 + 热搜词 + 热门小马 |
| GET | `/api/home/search` | 分级分类 + 关键词搜索（分页） |
| GET | `/api/category/tree` | 分类树（带每类条目数） |
| GET | `/api/pony/{id}` | 条目详情（含标签、分类、同类推荐） |
| GET | `/api/user/profile?id=` | 我的账号：注册时间 / 加入天数 / 同名图鉴小马 |
| POST | `/api/admin/login` | 管理员登录（复用 t_user，permission 0/2 可进） |
| GET | `/api/admin/me` | 校验 X-Admin-Token，返回当前管理员与权限 |
| GET | `/api/admin/user/list` | 后台用户列表（keyword 搜名字 + permission 筛选，-1=全部） |
| PUT | `/api/admin/user/{id}/password` | 后台重置密码（6~32 位；普通管理员只能重置普通用户） |
| POST | `/api/admin/message/send` | 发系统通知（toName 留空 = 全员广播 toId=-1） |
