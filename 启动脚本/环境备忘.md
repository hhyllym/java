### ⚠️ 两个必踩的坑

1. **一定要用 `mvn.cmd`，不要用 `mvn`（无后缀的 shell 脚本）。**
   在 Git Bash 里跑 `mvn` 会直接报：
   ```
   错误: 找不到或无法加载主类 org.codehaus.plexus.classworlds.launcher.Launcher
   ```
   这是 Git Bash 的路径转换把 Maven 的 classpath 弄坏了，不是 Maven 装坏了。
   同理 `~/.m2/wrapper/dists/` 里那两个发行包也一样，别用 `mvn` 脚本。

2. **启动后端前要清掉环境变量 `SERVER__PORT`。**
   Spring Boot 的宽松绑定会把它当成 `server.port`，于是 Tomcat 跑去监听一个随机端口，
   日志里会出现 `Tomcat initialized with port 58203` 然后 `APPLICATION FAILED TO START`。
   在自动化脚本里启动前先 `unset SERVER__PORT`。

## 3. 编译 + 启动后端（8081）

```bash

cd "D:/workSpace/springBootTest"
"/d/IntelliJ IDEA 2024.3.2.2/plugins/maven/lib/maven3/bin/mvn.cmd" -DskipTests package
unset SERVER__PORT
"C:/Program Files/Zulu/zulu-21/bin/java.exe" -jar target/springBootTest-0.0.1-SNAPSHOT.jar
```

- 默认 profile 是 `dev` → 端口 **8081**
- `application-test.properties` → 8080，`application-prob.properties` → 8082
- 停服务：`netstat -ano | grep ":8081.*LISTENING"` 拿 PID，再 `Stop-Process -Id <PID> -Force`

## 6. 页面深链（前端路由 query）

- `/home?category=12` —— 直接落在某个分类上（一级/二级都吃）
- `/home?pony=2` —— 直接弹出某个条目的详情
  「我的账号」页点同名小马 / 点分类就是靠这两个 query 跳过去的。
